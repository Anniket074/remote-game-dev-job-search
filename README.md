## 🧠 Institutional Knowledge (Critical for Continuation)

### Greenhouse ATS Gotchas
1. **Browser autofill corruption** — First Name = "NightAnniket", Last Name = "Charcha" on every load
   - **Fix:** Click field → `Control+A` → `Backspace` → `fill('Anniket')` *after* all other fields
2. **React-Select validation** — `.fill()` doesn't trigger `onBlur`
   - **Fix:** `pressSequentially('text', {delay: 10})` + `Tab` keypress
3. **Numeric CSS IDs** — `#4001506004` invalid selector
   - **Fix:** Use `role="combobox"` + `aria-label` or React-Select helper
4. **Conditional race dropdown** — "Asian" appears only after "Hispanic/Latino" selection
   - **Fix:** Explicit separate step for race after demographics

### LinkedIn Outreach Patterns
- Connection notes: ≤300 chars, reference specific tech (WebSockets, 90+ FPS, shipped count)
- Inbound screening: Answer all questionnaire points + attach resume PDF in-thread
- Track thread IDs for follow-up (LinkedIn sidebar has no stable anchors)
